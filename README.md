## 🚀 Run Locally

Follow these steps to run the project on your local machine.

### 1. Clone the Repository

```bash
git clone https://github.com/maazsiddiqui79/portfolio-design-01.git
```

### 2. Navigate to the Project Directory

```bash
cd portfolio-design-01
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm start
```

The application will start at:

```text
http://localhost:3000
```

Open the URL in your browser to view the application.

---

### 4. Start Exploring

Make changes to the HTML/CSS files and refresh the browser to see the changes.
